# Data Source Note

## Sources

| Source | Description |
|---|---|
| Primary | `dataset.csv` supplied with the project brief: 500 rows with date, product_id, category, season, stock_qty, reorder_level, daily_sales, unit_cost, supplier_id and lead_days. Stored unedited in `data/raw/` (excluded from version control because `unit_cost` contains real supplier prices). |
| Extended | 4,500 rows generated by `src/prepare_data.py` with a fixed seed (42), giving 5,000 rows, 500 SKUs, 30 suppliers and all twelve months of 2024. No external dataset was used. |

## Gap identified

The supplied file covers only the start of the year and holds a single `daily_sales` value per record, so a demand
model has no seasonal history to learn from. The generator adds documented seasonal multipliers and keeps each SKU's
base demand stable across records.

## Generation assumptions

| Item | Assumption |
|---|---|
| SKU demand | Base demand uniform between 10 and 50 units per day for each SKU |
| Seasonal multipliers | Winter 1.00, Summer 1.20, Monsoon 0.95, Festive_Diwali 1.40 (1 October to 15 November); random noise with standard deviation 10% |
| Stock | About 18% of records at or below the reorder level |
| Suppliers | 85% of orders from the SKU's primary supplier; lead time normally distributed around a supplier mean and clipped to 3-21 days |
| Anomalies | 150 synthetic rows (3%): 50 stock-outs, 50 demand surges (2.5-3.5 times normal) and 50 supplier delays (22-35 days). The original 500 rows are unchanged. |
| Cost | `unit_cost` converted to a Cost Index (median 100, plus or minus 2% noise) |

## Validation of the generated data

The summary printed by `src/prepare_data.py` and `reports/data_profile.txt` confirm: 5,000 rows, 500 SKUs, 30
suppliers, 12 months, no missing values, no duplicate rows and no negative stock or sales. Mean daily sales by season
follow the expected order: Festive_Diwali 43.1, Summer 36.9, Winter 31.3 and Monsoon 29.2 units per day.

## Known limitation

The `category` of a SKU is not consistent across the 500 original rows, so category analysis is performed at record
level.
