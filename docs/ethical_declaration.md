# Ethical Compliance Declaration

**Project:** Optimized Retail Inventory Management System (Project No. 21)
**Programme:** HCLTech Career Shaper Programme

Draft for review and signature. If the Programme Coordinator has issued an official declaration form, use that form.

I confirm that in this project:

1. **Anonymisation.** Supplier and product identifiers are pseudonymous codes (SUP01-SUP30, SKU0001-SKU0500). No names or contact details are held.
2. **Supplier pricing.** Real supplier unit costs were replaced with a relative Cost Index (median 100) before analysis. Real prices do not appear in the processed data, models, dashboard or report. The raw file is excluded from version control and is not submitted.
3. **Data minimisation.** Only the fields required for forecasting, alerts and supplier analysis are used.
4. **Generated data.** 4,500 of the 5,000 records were generated by script. The assumptions are documented in `docs/data_source.md`, and the report states that absolute metrics illustrate the method.
5. **Reporting.** Limitations and weaker results are reported alongside the successful ones.
6. **Sources and tools.** The libraries and AI tools used are cited in the report reference list.
7. **Confidential material.** The repository contains no passwords, API keys or personal data.
8. **Fairness.** The system does not make decisions about individuals.
